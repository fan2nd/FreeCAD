# FreeCAD 工程集合

每个工程放在 `projects/<工程名>/`。每个工程内部按用途统一分目录；各工程的版本目录各自使用相同结构。

```text
projects/<工程名>/（有版本时先进入 v1/、v2/、v3/ 等目录）
├── models/     FreeCAD 工程和 STEP 模型
├── scripts/    构建及预览生成脚本
├── previews/   PNG、SVG 预览
└── print/      STL、3MF 打印文件
```

仅创建实际有文件的目录。构建生成的 `reports/` 不提交；旧说明、校验脚本和草案集中保留在根目录 `.local/`，不进入 Git。

| 版本 | 工程 | 状态 |

| v3 | [管路压力工装](projects/tube-pressure-fixture/v3/models/管路压力工装.FCStd) | 当前版本：独立形变板，中央圆弧缺口R1.95，最薄0.6 mm、两侧2.2 mm，总高10.4 mm |

各版本分别保留 `models/`、`scripts/`、`print/` 和 `previews/`；工程根目录不再保留重复工作文件。v1原始时点备份已被覆盖，重建结果与当时上下件体积记录核对；v2直接复制当前文件，`snapshot.json`记录来源和校验值。v3采用下座、上盖、形变板三件结构。形变板24×8.9 mm，底部中央缺口与管道对中，上表面完整贴片；上盖两端各压住3 mm，限位槽单边间隙0.3 mm。圆弧顶部最薄0.6 mm，两侧厚2.2 mm；管道名义预压0.15 mm。两侧壁在板下中央9.7 mm范围降至Z6，板底距下座0.2 mm。下座限位段外端到上盖窗口、内端到形变板的间隙均为0.4 mm。上盖顶面和形变板贴片面均朝下打印，层高0.2 mm；三件STL已按该方向导出。装配预览见 [v3装配](projects/tube-pressure-fixture/v3/previews/assembly.png)，缺口截面见 [v3剖面](projects/tube-pressure-fixture/v3/previews/section.png)。上下盖及形变板无实体干涉，打印层支撑校验通过；尚未验证材料应变分布和量程。后续修改默认在v3内进行。

以下尺寸说明适用于v2，所列分类路径均相对于版本目录。

应变片基底采用用户确认的实际尺寸 **8.8 × 7.5 mm（长×宽）**。外框随贴片区缩小为42.5 × 36.6 mm，螺丝孔距为30.5 × 24.6 mm。基底居中贴在9.8 × 8.9 mm悬臂平面上，长度方向每端余量0.50 mm、宽度方向每侧余量0.70 mm。

- `models/`：FreeCAD 工程、两件装配 STEP，以及上盖、下座的单件 STEP。
- `scripts/history.py`：创建上下件的约束草图、拉伸、切除及合并依赖树；`rounded.py` 构造相切圆弧过渡；`.FCStd` 保留全部可编辑过程，中间特征默认隐藏；上盖、下座直接作为顶层对象，历史通过原生依赖树展开，不额外分组。可修改草图尺寸约束或拉伸长度并重算；参数表仍为记录表，尚未驱动这些特征。
- `scripts/build.py`：构建模型、导出打印文件并检查几何，同时验证草图尺寸和拉伸长度修改能传递到最终实体；`scripts/render.py`：在构建后生成 PNG 预览。两者均根据脚本位置定位工程目录。
- `scripts/final_view.py`：在 FreeCAD GUI 中执行，隐藏管道及应变片参考包络，只展示最终上盖、下座，适配轴测视图并保存。无界面重建后应执行此步骤；GUI 内重建会自动执行。
- `previews/`：PNG、SVG 分解预览，以及 `section.png` 管道中心装配剖面。
- `print/`：已摆好打印方向的 STL；下座底面朝下，上盖贴片面朝下。
- `reports/`：构建生成的检查结果和预览中间数据，由现有 Git 忽略规则排除。

上盖高度2.4 mm（0.2 mm层高，共12层），装配总高8.4 mm，悬臂贴片面位于Z=8.4 mm；下座螺丝柱顶面Z=6.4 mm。鞍面位置及0.20 mm预压保持不变。悬臂长9.8、宽8.9、厚0.6 mm（3层），触头端块同为0.6 mm；保留圆弧鞍面后实际触头中心厚0.65 mm、两侧厚约1.03 mm。敏感栅总区约7 × 7 mm，其下方均为0.6 mm薄梁。根部2.4 mm厚支撑以单圆弧R3.66 mm连接薄梁；自由端取消加厚台阶，以同厚薄梁连接触头，贴片面保持共面。四个焊点朝固定端（-Y）；暂定敏感栅距自由侧基底边0.35 mm，距焊点侧基底边1.45 mm，具体偏置需按实物校正。焊点侧增厚支撑，主要柔性区避开焊点区；基底完整支撑。7 × 7 mm仅为四栅总包络，不推定单栅间距或桥路输出。按 0.2 mm 层厚、薄梁实心设计。四颗 M3×6 普通螺丝按盘头、头下长度6 mm预留，上盖孔位厚2 mm，下座底孔为 Ø2.8 × 深4.8 mm的光孔，模型未生成螺纹。普通螺丝在该孔中的咬合需按打印材料试制验证；薄梁强度、3EB桥路与0–100 kPa量程尚未实测验证。

接触端块和凸台均以管道中心线对称。端块及鞍面沿管轴方向均为8.9 mm，与悬臂同宽；横向2.3 mm，三侧不留凸边，保留完整贴片支撑。下座测量段采用长18.1 mm、名义宽3.9 mm的顶部开放U形槽：底部R1.95圆弧承托，直壁顶面Z=8.4 mm；悬臂侧仅在中央10.1 mm长范围局部降至Z=7.2 mm，薄梁下方名义净距0.6 mm，其余侧壁保持原高，限制侧向及向下扩张，为向上推动舌片留出空间。此为几何约束设计，实际打印配合、轴向滑移与硅胶鼓胀仍需验证，不能视为完全单向变形。

接触头采用 R1.95 浅圆弧鞍面，沿管轴长8.9 mm、横向宽2.3 mm，与两侧约束壁各留0.80 mm名义间隙。鞍面相对未变形管道下移0.20 mm作为预压试样值，由硅胶压缩和薄梁上挠共同吸收；参考管与上盖的局部重叠是预压表达，不代表硬件互撞。触头和端块按上移0～0.6 mm、绕X轴±3°（枢轴Z=8.4 mm）、X/Y偏移±0.10 mm构建连续保守运动包络，与底座净距大于0.45 mm且不碰固定上盖框。这是几何活动空间校核，不是材料允许行程或实际压力响应验证；实际间隙和预压需结合打印误差试装。

## 文件管理约定

- 通用约束见 [AGENTS.md](AGENTS.md)，管路工装专用约束见 [管路工装约束](projects/tube-pressure-fixture/AGENTS.md)。FreeCAD 参数表的“数值”和“单位”分别放在独立列；文字说明另列或另表存放。
- 提交工程、构建脚本、预览和打印文件，以及本说明和 `.gitignore`。
- `models/` 中有意保留的原始模型（如 `h7s78-dk-original.FCStd`）是重建输入，不是自动备份。
- 脚本根据自身位置定位工程目录，输出到对应分类目录，不再使用 `output/`。
- 自动备份、缓存、临时文件、`reports/` 和 `.local/` 由 [.gitignore](.gitignore) 排除。
- 本次仅整理路径和脚本，不改变 CAD 几何；FreeCAD 最近文件列表可能需要重新选择新位置。
