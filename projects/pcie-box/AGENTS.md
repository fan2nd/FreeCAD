# 网卡收纳盒

- 对象：PCIe x8、标准半高、双SFP网卡，外观参考用户照片。
- 用户授权按标准卡尺寸设计，不要求先实测。
- 磁铁规格：直径4 mm、高2 mm；上下各4颗，共8颗。
- 网卡含PCIe挡片总长180 mm。用户要求外长保持180 mm，外宽86 mm、外高36 mm；外长不得再加长；最新要求左端仅挡片上侧折耳处开放，其余封闭。右端沿用开放。
- 左端壁厚3 mm，仅上侧挡片折耳保留13 mm宽通槽，上盖对应开槽；右端开放；磁铁座移到两侧，端口净宽80 mm、净高30.4 mm，磁铁座处净宽72 mm。上盖用两条侧向定位条，不设横跨端口的定位圈。
- 默认保留半高挡板、不插SFP模块；实际网卡宽厚及磁铁座避让未经试装。
- 保留上下盖完整可编辑历史、驱动参数表、闭合装配视图及打印方向导出。

- 内托必须按照片中主罩、PCB凸出部、金手指和挡片的阶梯轮廓限位，不能退回空白方槽。局部轮廓是以总长180 mm推算的近似值，须明确待实物试装；金手指不作为夹紧或承载面。
- 挡片侧磁铁中心距端面30 mm，另一端14 mm；定位条长124 mm、中心沿长向偏8 mm，以避开磁铁座。

- 用户实测：PCB板长166 mm，金属罩高于PCB上表面14 mm，散热片低于罩，背面凸起2 mm。板厚按1.6 mm设计假定；上下各留0.6 mm。板边承托高2.6 mm，盖内罩面限位凸台高11.6 mm。用户补充背面照片；6颗螺丝背面凸起1 mm，挡片侧2颗凸起2 mm。位置和螺丝头直径由照片估算，承托接触区域仍需试装核对。

- 阶梯内托高度由背面支承、板厚、金属罩高度和余量驱动（当前18.8 mm），形成明显的PCB凸出部与金手指轮廓。左端不得退回整面开口。

- 装配测试网卡不另建散热片，以金属壳14 mm包络包含散热片。网卡参考组件保留PCB、金手指、挡片及8颗螺丝的原生建模历史；实测与照片估算必须分开标明。

- 最新纠正：图中上下两侧阶梯轮廓壁直接延伸至顶盖接触面（内托高30.4 mm），取消与其干涉的盖内侧向定位条。网卡左上挡片上端不超出PCB顶边，左侧补双SFP接口外伸。SFP尺寸暂估外伸4、宽14、高11.5 mm，尚未实测。

- 侧视修正：挡片主体顶部高于金属壳1 mm；固定耳局部参考PCIe CEM 3.0图9-9，高出主体3.58 mm，耳宽18.59 mm、U槽宽4.42 mm。仍保留俯视上端与PCB顶边齐平。SFP从挡片外表面突出2.5 mm，宽向以相邻金手指侧PCB直角边向内偏移10 mm定位接口近边；接口宽14、高11.5仍为估算。

- 最新支撑要求：盖内两条金属壳限位面与壳顶直接接触（高12.2 mm，零名义间隙）。取消板边承托，改用八个直径5 mm圆柱托住螺丝头；六个高1.6 mm，挡片侧两个高0.6 mm。坐标仍按背面照片估算。保持PCB背面离底2.6 mm，元件区不承重。

- 螺丝中心已实测（背面朝上、挡片在右，以PCB左上角为原点）：①(3,5)、②(51.5,5)、③(103.5,5)、④(155,5)、⑤(3,51)、⑥(51.5,51)、⑦(103.5,51)、⑧(160,59.5)，单位mm。螺丝和支撑柱同步定位；头径仍为照片估算。

- 统一工程：`models/网卡收纳盒.FCStd`同时包含下盒、上盖、网卡及全部可编辑历史，默认闭合装配；`build.py`与`update_assembly.py`均构建完整工程。`网卡收纳盒.step`为完整装配，单件STEP/STL单独导出。旧的独立装配工程归档到reports，不再作为交付入口。

- 挡片耳避让已收窄：下盒仅在Y=32.95 mm处保留2.2 mm宽装入槽（耳厚1，两侧各0.6），补齐原左上角13 mm大缺口的多余部分；上盖取消耳槽恢复完整。下盒窄槽向上开放以便整卡垂直装入。

- 最新顶盖要求覆盖旧36 mm外高约束：顶盖为2.4 mm平板，与底板等厚，无下伸限位凸台；盖底直接贴金属壳。内腔深由2.6+1.6+14驱动为18.2 mm，盒体外高23 mm。仅挡片主体留1.6 mm深槽，固定耳留局部通槽；固定耳最高25.18 mm，局部高于盒面2.18 mm。

- 用户随后明确总高仍保持36 mm，并增加圆角，覆盖上一条23 mm：上盖及底板均厚2.4，盖底Z=33.6，PCB背面Z=18；八柱直径5，高14.6（六个）/13.6（两个）。内腔深31.2。上下壳外侧四条竖边R2原生圆角。挡片耳随卡抬升，最高38.18，局部高出36 mm盒面2.18；通过顶盖局部耳槽避让。

- 最新确定：允许降低总高，挡片耳不能超出上盖顶面。上下盖板均厚6 mm，内腔深18.6，总高30.6。六个支撑柱高2 mm、挡片侧两个高1 mm，直径5；PCB背面离底3 mm。顶盖内侧为贴金属壳的大平面，仅挡片主体及耳部做局部盲槽；耳槽深5 mm，上方保留1 mm盖板，耳顶距槽顶0.42 mm，距盖顶1.42 mm。保留外角R2。

- 最新外壳要求：长度允许增加，改为190×86×30.6 mm全包围外壳，两端封闭，挡片耳和卡尾均收入内部。俯视圆角矩形，侧视矩形；仅四条竖向外棱R2，不对上下水平边倒圆。顶盖耳槽为内部盲槽，不贯穿外壁和顶面。
