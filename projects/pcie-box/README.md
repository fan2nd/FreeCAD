# 网卡收纳盒

用于 PCIe x8 半高双 SFP 网卡，下盒和磁吸上盖两件。保留半高挡板，默认不插 SFP 模块。

| 项目 | 尺寸或数量 |
| --- | --- |
| 合盖外尺寸 | 180 × 86 × 36 mm |
| 端部 | 左端壁厚3 mm，仅上侧挡片耳槽宽13 mm；右端开放 |
| 磁铁座处净宽 | 72 mm |
| 轮廓壁高度 | 从底板上表面至顶盖接触面30.4 mm |
| 底厚 / 侧壁厚 | 2.4 / 3 mm |
| 盖板厚 | 3.2 mm |
| 磁铁 | Ø4 × 2 mm，共8颗，两侧端部各一对 |
| 磁铁孔 | Ø4.2 × 深2.15 mm |
| 盖内侧向定位条 | 已取消，避免与加高轮廓壁相撞 |
| 磁铁座 | 长10、宽6 mm，挡片侧中心距端面30 mm，另一端14 mm |

## 尺寸依据与边界

用户确认网卡含PCIe挡片总长180 mm，要求收纳盒外长保持180 mm，外宽86 mm、外高36 mm，最新要求左端仅挡片耳朵位置开放：增加3 mm端壁，照片上侧折耳留13 mm宽槽，上盖对应避让；其余左端封闭，右端沿用开放。

PCB板长166 mm、金属罩距PCB上表面14 mm、背面最大凸起2 mm均为用户实测；散热片低于金属罩，采用统一14 mm上方包络。板厚暂按1.6 mm设计假定。

内托高30.4 mm（等于内腔深，直接接触顶盖），形成贯穿内托高度的PCB与金手指阶梯轮廓，板长以166 mm驱动并留端部余量。金手指底部额外下切1 mm，底板剩1.4 mm，避空位置随板长联动。局部缺口与罩边仍依据照片推算，尚未实物试装。

四处板边承托高2.6 mm，使背面2 mm凸起与底板相隔0.6 mm；两处盖内限位凸台高11.6 mm，位于照片中金属罩区域，距罩顶0.6 mm。PCB下表面设计Z=5，上表面Z=6.6，罩顶Z=20.6，盖内限位底面Z=21.2。背面元件位置未知，仅验证中央区域避空，板边承托接触处仍需核对；不可把金手指当承载面。普通打印塑料不提供防静电保护，袋或软垫厚度会消耗间隙。

磁铁座局部净宽72 mm，中心距挡片端30 mm、另一端14 mm。左端壁仅耳槽开口，挡片主平面容纳在端壁内侧。照片轮廓保存在“卡轮廓”约束草图中，可编辑顶点；板长参数驱动纵向位置，局部相对比例并非实测。

## 文件与重建

- `models/网卡收纳盒.FCStd`：两个顶层Body及驱动参数、说明表；原生约束草图、Pad、Pocket保持依赖。
- `models/*.step`：闭合装配和两个单件。
- `print/下盒.stl`、`print/上盖.stl`：下盒底面朝下，上盖外表面朝下，均落在Z=0，孔朝上。
- `previews/assembly.png`、`previews/interior.png`、`previews/contour.png`：闭合、内腔及轮廓俯视预览；工程最终保存闭合状态。
- `scripts/build.py`：在FreeCAD Python控制台运行下列命令。脚本根据自身路径定位工程。

```python
p='/Users/fan/FreeCad/projects/pcie-box/scripts/build.py'

```

参数表数值、单位、说明分列，通过表达式驱动几何。修改参数后重新计算；重新运行脚本恢复脚本默认值，永久修改应同步脚本。

## 装配与验证

先干装磁铁并标记极性，上下对应磁铁应相吸，再胶粘，磁铁表面接近孔口齐平。孔深额外0.15 mm用于胶层。磁吸力、胶粘及打印公差需试装验证。

两件STL按无需支撑的方向导出。已检查有效单实体、所有草图完全约束、合盖交集为零、外形180×86×36、左端实体封闭、耳槽贯通、板身上方及中央背面包络无干涉、外长及实测板长/上下高度的参数联动与恢复、STL封闭。自动检查结果位于忽略提交的`reports/validation.json`。几何验证不等于实际网卡试装验证。

## 网卡装配检查

`models/网卡装配.FCStd` 包含原盒体及可编辑网卡组件：PCB阶梯轮廓、金属壳包络（包含散热片）、挡片、8颗螺丝、金手指及代表性背面元件。`models/网卡.step` 是独立网卡，`models/网卡装配.step` 是含盒装配。构建脚本为 `scripts/assembly_check.py`，依赖已保存的收纳盒工程；`scripts/show_fit.py` 添加真实布尔交集检查特征及预览。

用户实测：板长166 mm，上方14 mm；6颗底部螺丝凸起1 mm，挡片侧2颗凸起2 mm。照片中背面挡片在右，模型已镜像回正面方向。螺丝位置及直径、局部轮廓按照片估算；板厚1.6 mm、代表性背面元件高1 mm为设计假定。

上一轮测试发现的金手指槽右端干涉已通过局部加宽处理，现沿X余量约0.691 mm；挡片下端贴壁处增加避空。8颗螺丝均无体积干涉，6颗螺丝头下方竖向余量1.6 mm，挡片侧2颗余量0.6 mm；金属壳顶至盖限位面余量0.6 mm。网卡左上挡片上端已按用户纠正，与PCB顶边齐平；左侧补双SFP接口，外伸4、宽14、高11.5 mm暂按示意估算。`干涉检查`中两项为原生Common，默认隐藏，可显示并追溯引用。具体结果在 `reports/assembly_check.json`。以上是近似模型校核，不能替代实物试装。

- 侧视修正：挡片主体顶部高于金属壳1 mm；固定耳局部参考PCIe CEM 3.0图9-9，高出主体3.58 mm，耳宽18.59 mm、U槽宽4.42 mm。仍保留俯视上端与PCB顶边齐平。SFP从挡片外表面突出2.5 mm，宽向以相邻金手指侧PCB直角边向内偏移10 mm定位接口近边；接口宽14、高11.5仍为估算。

- 最新支撑要求：盖内两条金属壳限位面与壳顶直接接触（高12.2 mm，零名义间隙）。取消板边承托，改用八个直径5 mm圆柱托住螺丝头；六个高1.6 mm，挡片侧两个高0.6 mm。坐标仍按背面照片估算。保持PCB背面离底2.6 mm，元件区不承重。

- 螺丝中心已实测（背面朝上、挡片在右，以PCB左上角为原点）：①(3,5)、②(51.5,5)、③(103.5,5)、④(155,5)、⑤(3,51)、⑥(51.5,51)、⑦(103.5,51)、⑧(160,59.5)，单位mm。螺丝和支撑柱同步定位；头径仍为照片估算。

- 统一工程：`models/网卡收纳盒.FCStd`同时包含下盒、上盖、网卡及全部可编辑历史，默认闭合装配；`build.py`与`update_assembly.py`均构建完整工程。`网卡收纳盒.step`为完整装配，单件STEP/STL单独导出。旧的独立装配工程归档到reports，不再作为交付入口。

- 挡片耳避让已收窄：下盒仅在Y=32.95 mm处保留2.2 mm宽装入槽（耳厚1，两侧各0.6），补齐原左上角13 mm大缺口的多余部分；上盖取消耳槽恢复完整。下盒窄槽向上开放以便整卡垂直装入。

- 最新顶盖要求覆盖旧36 mm外高约束：顶盖为2.4 mm平板，与底板等厚，无下伸限位凸台；盖底直接贴金属壳。内腔深由2.6+1.6+14驱动为18.2 mm，盒体外高23 mm。仅挡片主体留1.6 mm深槽，固定耳留局部通槽；固定耳最高25.18 mm，局部高于盒面2.18 mm。

- 用户随后明确总高仍保持36 mm，并增加圆角，覆盖上一条23 mm：上盖及底板均厚2.4，盖底Z=33.6，PCB背面Z=18；八柱直径5，高14.6（六个）/13.6（两个）。内腔深31.2。上下壳外侧四条竖边R2原生圆角。挡片耳随卡抬升，最高38.18，局部高出36 mm盒面2.18；通过顶盖局部耳槽避让。

- 最新确定：允许降低总高，挡片耳不能超出上盖顶面。上下盖板均厚6 mm，内腔深18.6，总高30.6。六个支撑柱高2 mm、挡片侧两个高1 mm，直径5；PCB背面离底3 mm。顶盖内侧为贴金属壳的大平面，仅挡片主体及耳部做局部盲槽；耳槽深5 mm，上方保留1 mm盖板，耳顶距槽顶0.42 mm，距盖顶1.42 mm。保留外角R2。

- 最新外壳要求：长度允许增加，改为190×86×30.6 mm全包围外壳，两端封闭，挡片耳和卡尾均收入内部。俯视圆角矩形，侧视矩形；仅四条竖向外棱R2，不对上下水平边倒圆。顶盖耳槽为内部盲槽，不贯穿外壁和顶面。
