# HT2806

- 用户提供的HT2806安装尺寸截图是本工程尺寸依据。
- 本工程包含电机安装外形、CW32支架和驱动板参考；不推定内部电磁和轴承结构。
- 图中未给孔深、公差、剖面和完整出线结构；本工程的暂定值见参数表说明列和README。
- 主工程入口为 `models/HT2806.FCStd`。
- 原始参考图保存在 `references/`：安装尺寸图用于几何，性能参数图用于性能记录。规格表无编码器总长18.3与尺寸图推算18存在差异，未经澄清不覆盖现有几何。
- 工程内“性能记录”表不驱动几何；“尺寸参数”表驱动几何。

- 所有零件留在唯一HT2806.FCStd；build.py统一重建电机、支架及螺丝，mount.py建立原生支架历史，禁止另拆工程。
- 用户确认原图Ø12×3凸台就是磁铁；中央Ø13闭合直孔，径向间隙0.5，不使用向内收口。上侧保留2 mm高连接壁。
- 电机后侧矩形孔取对角两颗M2×6沉头内梅花螺丝，总长含头部6，头径Ø3.7，T6；商品头厚1.7仅记录。用户接受90°锥角假设；立板厚6，Ø4.2入口孔深2，再接Ø3.7至Ø2.2、深0.75锥座；头顶距电机面4，旋入2。参考图为references/M2x6沉头螺丝.png，实际锥角和就位需试配。
- PCB元件槽Ø32.6深1.6 mm，保留两柱根，板柱露出立板背面0.6 mm，根部Ø5.2、顶端Ø4。PCB仍用两颗M2.5×6自攻，导孔Ø2.0、有效深4.4，距电机面2.2 mm。
- PCB板厚1.6、SOP8高1.75为假设。板背距电机面6.6，封装表面4.85，磁铁间隙1.85。板底至槽底2.2 mm、至电机螺丝头2.6 mm；按元件高度1.75包络校验余量0.45，真实元件/焊点高度和磁性能需实物确认。
- 顶部R17.3与电机Ø34.6一致；底板46×40×5，立板宽46，轴心高27；底脚R8、底板角R4。
- 电机背面方块为出线位置；缺口朝上、宽8、深8.8，底角R2及口角R2；槽底轴心上方8.5。原方块尺寸按图估计。
- 仅保留底板与立板连接双孔，其中心随立板厚调整至3 mm；其他电机和板孔位不变。4621工程不修改。
- 最终显示电机、立板、底板及电机螺丝；PCB参考隐藏。立板以电机贴合面朝下打印，主工程为真实装配。

- 严格按首层及层高0.2 mm：立板打印高度槽底4.4、背面6、柱顶6.6、自攻孔底2.2；底板厚5，底面沉孔深2.6。脚本校验整层平面，沉头锥面保持90°配合。
