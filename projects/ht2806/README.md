## CW32 支架

唯一工程`models/HT2806.FCStd`包括电机、立板、底板、两颗电机螺丝参考及隐藏的PCB参考，均保留可编辑原生历史。`scripts/build.py`统一重建，`mount.py`构建支架；不依赖额外FCStd输入。

立板厚6 mm，板背开Ø32.6、深1.6 mm元件避让槽，保留两处柱根。两根锥柱从立板背面抬高0.6 mm，根部Ø5.2、PCB接触端Ø4。PCB两颗M2.5×6自攻，导孔Ø2.0，按板厚1.6计算咬合4.4 mm，末端距电机安装面2.2 mm。

电机固定用用户提供的M2×6沉头内梅花螺丝，T6，总长6 mm包含头部，头径约Ø3.7。商品图记录头部厚1.7 mm，但未标锥角；用户同意按90°暂定，因此头部锥段从Ø3.7缩到Ø2的深度为0.85 mm，1.7 mm不直接作为锥孔深度。原图已保存为`references/M2x6沉头螺丝.png`。

螺丝头顶距电机面4 mm、末端进入电机2 mm。立板背面先开Ø4.2、深2 mm的入口孔，再接90°沉头锥座（入口Ø3.7、末端Ø2.2、深0.75）；理论按锥面就位，不另加会改变旋入量的轴向余量。模型接触和旋入按理想几何核对，打印误差、实际锥角与就位深度需试装。螺丝参考不生成牙型和内梅花槽。

PCB相对原2.5 mm支柱降低1.9 mm，底面距螺丝头顶2.6 mm、距槽底2.2 mm。按板底元件高1.75 mm假设包络，距槽底余0.45 mm；包络排除支柱接触区，不能替代真实元件/焊点测量。

用户确认电机图纸Ø12×3凸台就是磁铁。磁铁孔为Ø13闭合直孔，径向间隙0.5。当前PCB底面距电机面6.6，按SOP8封装高1.75，封装表面位置4.85，至磁铁表面名义距离1.85 mm，比原2.5 mm支柱方案缩短1.9 mm，尚未验证编码器磁场/信号是否满足要求。

- 顶部外圆R17.3与电机Ø34.6一致。底板46×40×5，立板宽46，轴心高27，名义圆顶高44.3；底脚R8、底板角R4。
- 电机后侧16×20.5矩形孔取对角两颗M2；出线方块朝上，孔位(±10.25,∓8)。PCB柱占另一对角方向，孔距19。
- 上缺口宽8、相对圆顶深8.8，底角R2、口角R2；槽底轴心上方8.5，距磁铁孔上缘6.5保留2 mm高、槽底剩余4.4 mm厚连接壁。用户确认背面方块是出线位置，方块尺寸仍为图纸比例估算。
- 底板仅保留两处连接孔：Ø3.3通孔、Ø5.5深2.6沉孔；立板Ø2.5深5.2导孔。连接孔中心随6 mm立板改到3 mm。
- 支架表中的功能参数驱动几何；外轮廓、缺口及口角记录项在对应原生草图/特征中编辑。

`models/立板.step`、`底板.step`和`支架.step`为打印零件；`装配.step`含电机和螺丝参考，`HT2806.step`为单电机。`print/立板.stl`电机贴合面朝下、`print/底板.stl`底面朝下；首层及层高均0.2 mm；打印高度槽底4.4、立板背面6、柱顶6.6、自攻孔底2.2均为整层，底板厚5、沉孔深2.6；脚本校验上述平面高度。锥柱向上收小，底脚横孔收口需切片检查。`previews/装配.png`为真实装配，`支架.png`、`立板.png`便于检查零件。
