# 推力计与笔槽板

底板233×70 mm，适配256×256 mm打印平台。保留四个M4安装孔，底面杯头沉孔直径7.3 mm、深2 mm，螺丝处剩余板厚6 mm。实测杯头直径6.7 mm、高3.6 mm，安装后突出底面1.6 mm。笔槽区保持原厚度。

- models：可编辑FreeCAD装配及STEP。
- print：底板STL，底面朝下。
- scripts：构建、尺寸图和已确认测量值。
- annotation-site/dist：本地尺寸标注页面，标注保存于浏览器。

几何有效性、四个沉孔切除体积、参数重计算及装配无实体干涉检查通过。部分尺寸仍为未确认占位；以参数表说明为准。FreeCAD界面发生异常，最终视图检查未完成，assembly.png不作为完整装配展示依据。
