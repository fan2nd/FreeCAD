# 4621-cw32

独立工程：`models/4621-cw32.FCStd`。立板与板安装柱一体打印，底板改为64×55×6 mm，与立板等长，外围四孔删除，仅保留两个连接沉孔。原支架只按用户后续要求把出线缺口移到上沿并改为8 mm深；其他结构独立维护。

## 当前结构

- cw32顶部缺口宽14 mm、深12 mm、底角R4，缺口与顶部外圆弧相接的两个口角加R2圆角；从原顶部圆弧最高点（中心上方23 mm）向下量，槽底位于中心上方11 mm。取消走线斜坡，改为贯穿6 mm板厚的直通开口；电机线及U/V/W（板上A/B/C）接口朝上，底部封平。
- 三相焊孔区域下方增加让位；验证中心上方13 mm起、宽10 mm的连续出线窗口贯穿板厚且无实体阻挡。窗口为预留空间，不代表已测得实际焊点或线束包络，实际线径和焊后形状需试装确认。原工程的缺口仍为8 mm。
- 中央按Ø16.4圆挖空，孔缘保留两根Ø5.2柱位；无矩形支臂、无中间台阶、无六角螺母槽。原独立编码器四孔及方形凹位移除。
- 板固定两颗M2.5自攻、电机固定两颗M3，两组孔分别在互相垂直的对角线上，形成X字；另外两个电机安装孔取消。
- 使用较小的一对板孔（图纸Ø2.6），孔距19 mm，改用M2.5自攻螺丝。支柱导孔暂定Ø2.0贯通；建议头下长6 mm，按板厚1.6 mm计算进入塑料4.4 mm，末端恰好到电机贴合面，长度余量为0。导孔需按实际自攻牙型和材料试配。
- 取消独立垫片。柱底靠中央孔侧做45度斜面：入口半径8.2、深1.3、末端半径6.9 mm。用户确认入口Ø16.4再以45度向内缩小；深入1 mm处直径14.4 mm。因此此处不是Ø16圆柱凸起的完整避让空间，装配需按实际凸起形状校核。

## 板位与打印

板背距电机贴合面4.4 mm；编码器封装暂按1.75 mm，封装表面位置2.65 mm。用户最新磁铁凸出小于1 mm，机械间距约1.65–2.65 mm；并非芯片内部感应面距离，实际高度及磁性能未验证。板背Ø32.8、深3.5 mm元件凹槽保留，槽底至板背1.9 mm。参考PCB不含真实元件。

立板以电机贴合面朝下打印。柱底45度斜面逐层收口，无螺母槽桥接；原底部横孔仍需检查切片收口质量。底板按新尺寸重新打印，未完成实机打印验证。
