# 4621-cw32

- 当前新支架在本工程独立维护。原工程仅按用户后续授权修改上沿出线槽及8 mm深度，不同步其他新支架特征。
- 保留真实可编辑历史和参数依赖，模型、构建脚本和导出同步。
- 原独立编码器四孔及方形凹位删除，板载编码器与电机同心。
- 用户最终要求M2.5自攻，使用较小一对板孔（图纸Ø2.6），孔距19。导孔暂定Ø2.0；无螺母。
- A/B/C接口、电机线朝上，cw32缺口从顶部原圆弧最高点向下12 mm，宽14 mm；直通且无走线斜坡，原支架仍保持8 mm，底部缺口取消。
- 中央按Ø16.4圆挖空，孔缘保留Ø5.2柱位，无矩形支臂或中间台阶。
- 不使用垫片；柱底电机侧用45度斜面让开Ø16、凸出小于1 mm的凸起。入口半径8.2、深1.3、末端半径6.9；用户确认入口Ø16.4再向内收小，深入1 mm处直径14.4；不按Ø16×1圆柱无干涉验收。
- 保持PCB背面位置4.4 mm，SOP8封装暂按1.75；磁铁机械间距约1.65–2.65 mm。真实元件、焊后高度、自攻牙型与磁性能需实物验证。
- 保留板背元件凹槽；参考PCB默认隐藏。立板电机贴合面朝下打印，最终显示真实装配。

- 当前驱动板两颗M2.5自攻、电机两颗M3，分别位于两条互相垂直的对角线，呈X字；去掉另外两个电机孔，仅改新支架。

- PCB正面与立板背面齐平，由板背位置=立板背面位置−板厚驱动；M2.5×6螺丝长度按头下计，理论末端到电机贴合面，无正余量。

- 用户最新要求：底板长度与立板一致，改为64 mm；宽55、厚6保持，外围四个Ø4.4孔删除，仅保留两个连接立板的沉孔。同步工程、STEP与底板STL。

- 出线缺口仅在与顶部R23外圆弧相接的两个口角加R2圆角；不对槽底或前后口沿整体倒圆。
